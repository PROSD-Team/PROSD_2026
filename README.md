# PROSD_2026

1. Встановити та запустити Docker.

2. Відкрити папку з проєктом та перейти у директорію:
   PROSD.backend.net/PROSD.backend.net

3. Запустити backend командою:
   docker compose up --build

4. Відкрити новий термінал та перейти у директорію:
   frontend

5. Встановити залежності (потрібно лише при першому запуску):
   npm install

6. Запустити frontend:
   npm run dev

7. Відкрити у браузері:
   http://localhost:5173/home
